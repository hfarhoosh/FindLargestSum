# FindLargestSum
A program written in Python designed to calculate the largest sum in an integer array, by adding neighboring elements. Tge number of neighboring elements to add varies from 1 (just a single element in the array) and all the elements in teh array.

For example, if input is [15, -34, 88, 435, -2578, 2, 333] the largest element would first be 435 (element 3) and then changed to (88+435)
